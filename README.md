# licheng-AGENTS.md

本仓库用于保存法律工作相关的 Codex/Agent 指令文件，便于在不同项目中复用统一的工作立场、法律核验边界、文档格式和合同审查起草流程。

## 文件说明

- `法律业务通用指令.md`：法律业务通用指令（V3）。覆盖指令效力与冲突解决优先级、利益立场与利益冲突停止条件、保密与脱敏红线（含脱敏核验程序）、事实与法律依据核验（反编造红线，含核验触发条件与降级顺序）、任务分流与执行流程、不确定性表述与风险分级、起草与修订规则（含一致性校验）、引用与出处格式、Word 文档格式规范、文件命名与版本交付、律所署名、跨境与外国法事项、多 Agent 协作规则、交付前自检清单和权威核验来源清单、本机 OCR 工具指引两个附录。
- `为什么这些规则要写进全局指令.md`：《法律业务通用指令》（V3）逐条说明。先立"三层指令"划分标准（每次开对话都要重说的写全局、仅项目内要说的写项目指令、只说一次的对话里说），再逐章说明各章为什么写在全局：冲突解决必须居最高层；保密与反编造红线因"需要保密的时刻恰是想不到提醒的时刻"必须常驻；禁令与降级退路必须绑在一起；七类任务分流与交付标准跨项目统一；起草默认值的价值在于每次都是同一个数字；引用与 Word 格式属纯规范问题写死全局；律所署名等永不变事实一次写对；外国法执业资格边界恒定且中国法一侧须同时作答；清理模型默认话术必须常驻；多 Agent 五段式回报格式与"登记不等于出资"原则全局适用；末尾自检清单用于重新激活长指令后半段衰减的约束力；并附"什么不该写进全局"清单。

## 使用建议

- 需要通用法律工作规则时，优先使用 `法律业务通用指令.md`。
- 任务集中在合同审查、协议修订或合同起草时，可在 `法律业务通用指令.md` 的基础上叠加使用 `合同审查和起草.md`。
- 任务涉及有限公司整体变更为股份有限公司、股改会议文件、发起人协议、章程制度或签署前复核时，可叠加使用 `股改文件起草.md`。
- 任务涉及法律培训、项目汇报、会议展示或专业服务 PPT 制作与修改时，可叠加使用 `法律PPT设计.md`。
- 任务涉及 IPO 法律尽职调查报告的整体起草、分章修订、摘要与正文同步、释义规范、附件及补充材料清单整理时，可叠加使用 `IPO法律尽职调查报告全流程起草提示词.md`，并先填写项目公司、报告期、最新底稿、资料路径及本次修改范围。
- 任务涉及从零梳理或增量更新 IPO 股权历史沿革表、按历次股权变动归档底稿文件夹，或同步更新尽调报告历史沿革章节时，可使用 `IPO股权历史沿革梳理与底稿归档提示词.md`，并在项目参数中限定本次仅处理表格、底稿、报告或全部内容。
- 任务涉及法律尽职调查报告起草、工商内档核查、股权历史沿革梳理或尽调底稿整理时，可叠加使用 `法律尽调报告提示词.md`；当前版本仅覆盖股权历史沿革部分。
- 任务涉及基于母版起草或定稿法律尽职调查清单、自然人股东及董监高调查表，或需要统一调查期间、独立回溯期间、用户修改和最终验收口径时，可叠加使用 `法律尽职调查清单起草与定稿.md`。
- 任务涉及非诉项目底稿目录搭建、资料清单转文件夹或尽调底稿标准化归档时，可叠加使用 `非诉业务常用提示词.md`；需要逐项建立三级目录时使用第一项提示词，通常只建立两级目录且仅特定章节增加三级时使用第二项提示词。
- 任务涉及上市公司重大资产重组项目竞聘、同类交易案例检索、监管问询归纳、交易结构及对赌方案研究或述标准备时，可复制 `上市公司重大资产重组竞聘-案例检索报告-提示词模板.md`，先替换变量区，再按项目板块、支付方式、交易角色和特殊交易类型调整核心指令。
- 任务涉及竞聘拟上市、拟挂牌或北交所上市企业法律顾问，需要解析企查查资料包、梳理公司基本情况、检索同行业审核实践并形成初步法律问题报告时，可叠加使用 `拟上市、挂牌企业公司基本情况及法律问题初步分析报告（竞聘法律顾问用）提示词.md`。
- 任务需要根据公司资料和公开信息快速形成 IPO 法律尽调报告初稿，或只修改释义、公司基本情况、股东实控人、附属公司、关联方、知识产权、公司治理及诉讼处罚等指定章节时，可使用 `根据公开数据起草尽调报告初稿.md`。
- 任务涉及股东出资银行流水、机构股东穿透、间接自然人或合伙人实际出资、出资前后六个月流水期间，或需要在现有出资流水备忘录第三部分局部增列字段时，可使用 `股东出资银行流水及间接股东核查提示词.md`，并以最新备忘录和原始银行凭证为唯一事实底稿。
- 任务需要从零梳理或更新 IPO 股东出资流水、核查资金来源、统一“提供情况”表述、同步重命名底稿文件夹并完成 Word/PDF 验收时，可使用 `IPO股东出资流水及底稿归档核查提示词.md`；如仅修改既有备忘录第三部分的间接股东表格，可叠加使用前一专项提示词。
- 任务涉及报告期延长后底稿覆盖时点核查与补充/删除清单编制、底稿目录与文件夹完整性比对、新三板挂牌转北交所上市目录修订、同类项目底稿目录逐章比对、全文措辞批量替换或底稿目录新增表格行/小节时，可使用 `律师工作底稿更新与目录修订提示词.md`，按需复制对应提示词并替换【】内信息；其中的 docx 修订痕迹技术要点亦可作为其他 Word 修订任务的参考。
- 任务涉及依据最新企查查报告更新董监高、核心技术人员及直接持股自然人调查表中的对外投资、任职、风险事项，统一调查期间表述，按修订模式制作修订版并清理文件名时，可使用 `IPO董监高及核心技术人员调查表更新提示词.md`，并先填写项目名称、各资料目录路径及调查表更新日期。
