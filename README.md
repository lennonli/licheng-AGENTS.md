# licheng-AGENTS.md

本仓库用于保存法律工作相关的 Codex/Agent 指令文件，便于在不同项目中复用统一的工作立场、法律核验边界、文档格式和合同审查起草流程。

## 文件说明

- `法律业务通用指令.md`：法律业务通用指令。覆盖默认服务立场、保密要求、法律依据核验、反编造规则、文档修订模式、起草默认值、Word 文档格式、律所署名、跨境事项提示和交付方式等通用要求。
- `合同审查和起草.md`：合同审查与法律文件起草专项指令。重点规定合同审查流程、风险分级、缺失条款补充、文字和格式校对、修订模式、合同起草要点、编号规则、签署页安排和版本命名规则。
- `股改文件起草.md`：有限公司整体变更为股份有限公司的股改文件起草专项指令。覆盖项目输入、资料填报、文件范围、特殊治理结构适配、一致性检查、模板残留清理、格式校验、缺失信息处理和最终交付要求。
- `法律PPT设计.md`：法律及专业服务 PPT 设计风格指令。重点规定简洁专业的视觉风格、页面结构、字体层级、信息呈现、视觉元素使用、既有 PPT 修改边界和新建 PPT 初稿确认流程。
- `IPO法律尽职调查报告全流程起草提示词.md`：IPO 法律尽职调查报告全流程起草与修订提示词。覆盖资料依据、修改边界、事实认定、释义、摘要、正文十三章、附件、补充材料清单、格式版本及交付验收要求。
- `IPO股权历史沿革梳理与底稿归档提示词.md`：IPO 股权历史沿革专项提示词。覆盖工商及交易证据核验、股权变动事件归并、历史沿革表、底稿文件夹整理、尽调报告更新、缺失材料清单和 Excel、Word、底稿交叉验收。
- `法律尽调报告提示词.md`：法律尽职调查报告专项提示词。当前先收录股权历史沿革部分，覆盖工商内档核查、股权变动底稿 PDF 拆分、历史沿革正文起草、补充材料清单和交付验收要求，后续可继续追加其他尽调章节。
- `法律尽职调查清单起草与定稿.md`：法律尽职调查清单及自然人调查表起草与定稿专项指令。覆盖母版保留、调查范围、外部核查线索转化、清单完善、独立回溯期间、用户修改优先、清洁版命名和 Word/PDF 全面验收要求。
- `非诉业务常用提示词.md`：非诉项目常用操作提示词。现收录尽调底稿三级目录制作提示词，以及通常建立两级、第四章按实际结构增加三级的二级目录生成提示词；统一规范正文主表读取、附表排除、既有资料保护、陈述式命名、非法字符处理、去重重编号和目录验收。
- `上市公司重大资产重组竞聘-案例检索报告-提示词模板.md`：上市公司重大资产重组项目竞聘案例检索报告复用模板。覆盖项目变量替换、客户情报与案例检索、法律规则核验、完整版 Word 报告结构、业绩承诺与商誉减值分析、项目时间表、述标问答、数据来源和质量自检要求。
- `拟上市、挂牌企业公司基本情况及法律问题初步分析报告（竞聘法律顾问用）提示词.md`：拟上市或挂牌企业竞聘法律顾问用公司基本情况及法律问题初步分析报告提示词。覆盖企查查资料包及表格解析、公开信息交叉核验、同行业审核案例检索、法律风险分级、报告章节、Word 格式和质量红线。
- `根据公开数据起草尽调报告初稿.md`：根据公司资料及经核验公开信息起草 IPO 法律尽职调查报告初稿的精简提示词。覆盖最新底稿优先、指定章节修改、事实边界、公开信息使用、主要章节口径、清洁 Word 版本和交付核验。
- `股东出资银行流水及间接股东核查提示词.md`：股东出资银行流水及间接股东出资核查专项提示词。覆盖机构股东和持股平台穿透、第三部分原格式增列实际出资金额/日期/银行/前后六个月流水期间/备注、逐笔付款证据核验、间接股东身份勾稽、差异处理及 Word/PDF 验收。
- `IPO股东出资流水及底稿归档核查提示词.md`：IPO 股东出资流水、资金来源核查及底稿归档通用提示词。覆盖直接及间接股东付款证据、前后六个月流水期间、提供情况统一口径、底稿文件夹命名、Word/PDF 验收和交付说明。
- `律师工作底稿更新与目录修订提示词.md`：律师工作底稿更新与目录修订 AI 提示词手册。覆盖报告期延长底稿更新清单、底稿文件夹完整性核查、新三板转北交所目录修订、同类项目比对、批量措辞替换、新增表格行/小节六个可复用提示词，并附底稿核查逻辑、docx 修订痕迹技术要点、覆盖时点重点表、比对方法论和格式命名规范。
- `IPO董监高及核心技术人员调查表更新提示词.md`：IPO 董监高、核心技术人员及直接持股自然人调查表更新专项提示词。覆盖企查查报告核查口径、人员归类与不更新规则、对外投资/任职/风险事项核查边界、调查期间统一表述、docx 修订模式、文件名清理和十项交付验收要求。

## 使用建议

- 需要通用法律工作规则时，优先使用 `法律业务通用指令.md`。
- 任务集中在合同审查、协议修订或合同起草时，可在 `法律业务通用指令.md` 的基础上叠加使用 `合同审查和起草.md`。
- 任务涉及有限公司整体变更为股份有限公司、股改会议文件、发起人协议、章程制度或签署前复核时，可叠加使用 `股改文件起草.md`。
- 任务涉及法律培训、项目汇报、会议展示或专业服务 PPT 制作与修改时，可叠加使用 `法律PPT设计.md`。
- 任务涉及 IPO 法律尽职调查报告的整体起草、分章修订、摘要与正文同步、释义规范、附件及补充材料清单整理时，可叠加使用 `IPO法律尽职调查报告全流程起草提示词.md`，并先填写项目公司、报告期、最新底稿、资料路径及本次修改范围。
- 任务涉及从零梳理或增量更新 IPO 股权历史沿革表、按历次股权变动归档底稿文件夹，或同步更新尽调报告历史沿革章节时，可使用 `IPO股权历史沿革梳理与底稿归档提示词.md`，并在项目参数中限定本次仅处理表格、底稿、报告或全部内容。
- 任务涉及法律尽职调查报告起草、工商内档核查、股权历史沿革梳理或尽调底稿整理时，可叠加使用 `法律尽调报告提示词.md`；当前版本仅覆盖股权历史沿革部分。
- 任务涉及基于母版起草或定稿法律尽职调查清单、自然人股东及董监高调查表，或需要统一调查期间、独立回溯期间、用户修改和最终验收口径时，可叠加使用 `法律尽职调查清单起草与定稿.md`。
- 任务涉及非诉项目底稿目录搭建、资料清单转文件夹或尽调底稿标准化归档时，可叠加使用 `非诉业务常用提示词.md`；需要逐项建立三级目录时使用第一项提示词，通常只建立两级目录且仅特定章节增加三级时使用第二项提示词。
- 任务涉及上市公司重大资产重组项目竞聘、同类交易案例检索、监管问询归纳、交易结构及对赌方案研究或述标准备时，可复制 `上市公司重大资产重组竞聘-案例检索报告-提示词模板.md`，先替换变量区，再按项目板块、支付方式、交易角色和特殊交易类型调整核心指令。
- 任务涉及竞聘拟上市、拟挂牌或北交所上市企业法律顾问，需要解析企查查资料包、梳理公司基本情况、检索同行业审核实践并形成初步法律问题报告时，可叠加使用 `拟上市、挂牌企业公司基本情况及法律问题初步分析报告（竞聘法律顾问用）提示词.md`。
- 任务需要根据公司资料和公开信息快速形成 IPO 法律尽调报告初稿，或只修改释义、公司基本情况、股东实控人、附属公司、关联方、知识产权、公司治理及诉讼处罚等指定章节时，可使用 `根据公开数据起草尽调报告初稿.md`。
- 任务涉及股东出资银行流水、机构股东穿透、间接自然人或合伙人实际出资、出资前后六个月流水期间，或需要在现有出资流水备忘录第三部分局部增列字段时，可使用 `股东出资银行流水及间接股东核查提示词.md`，并以最新备忘录和原始银行凭证为唯一事实底稿。
- 任务需要从零梳理或更新 IPO 股东出资流水、核查资金来源、统一“提供情况”表述、同步重命名底稿文件夹并完成 Word/PDF 验收时，可使用 `IPO股东出资流水及底稿归档核查提示词.md`；如仅修改既有备忘录第三部分的间接股东表格，可叠加使用前一专项提示词。
- 任务涉及报告期延长后底稿覆盖时点核查与补充/删除清单编制、底稿目录与文件夹完整性比对、新三板挂牌转北交所上市目录修订、同类项目底稿目录逐章比对、全文措辞批量替换或底稿目录新增表格行/小节时，可使用 `律师工作底稿更新与目录修订提示词.md`，按需复制对应提示词并替换【】内信息；其中的 docx 修订痕迹技术要点亦可作为其他 Word 修订任务的参考。
- 任务涉及依据最新企查查报告更新董监高、核心技术人员及直接持股自然人调查表中的对外投资、任职、风险事项，统一调查期间表述，按修订模式制作修订版并清理文件名时，可使用 `IPO董监高及核心技术人员调查表更新提示词.md`，并先填写项目名称、各资料目录路径及调查表更新日期。
- 如具体项目已有客户身份、交易背景、特殊争议解决安排或文件模板，应以具体项目指令优先，并与本仓库规则保持一致。

## 维护规则

- 每次更新本仓库内任何 Markdown 文件时，应同步更新本 README 的“更新记录”部分。
